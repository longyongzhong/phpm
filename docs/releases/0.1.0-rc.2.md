# PHPM 0.1.0-rc.2

新增 Debian 12 支持和 xlswriter 预编译扩展的公开候选版本，供功能验收。

- 客户端：Windows amd64、Linux amd64。
- 自建 PHP：Debian 12 x86_64 / glibc 2.36 与 Debian 13 x86_64 / glibc 2.41，各自提供 PHP 8.4.27、8.5.12 NTS CLI/FPM、SDK、Redis 6.3.0 和 xlswriter 3.0.0 独立扩展包。
- 客户端按系统匹配包；不混用 Debian 12/13 构建，不在源失败时切换第三方来源。
- 四套组合通过 SDK 迁移重编译、XLSX 写入读取、CLI/FPM 加载、项目隔离、冻结恢复及测试密钥 HTTPS 签名源验收。
- 正式根授权签名目录、客户端清单与全部 39 个上传资产的名称、大小、摘要已核对。下载后的独立签名验证与 Windows 客户端试装通过。
