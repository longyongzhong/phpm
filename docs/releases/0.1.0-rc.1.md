# PHPM 0.1.0-rc.1

首个使用维护者正式发布密钥签名的公开候选版本，供功能验收。

- **客户端**：Windows amd64、Linux amd64。
- **自建 PHP 包**：仅 Debian 13 x86_64 / glibc 2.41 / NTS，包含 PHP 8.4.27、8.5.12、各自匹配的 Redis 6.3.0 和 SDK。Debian 12 先测试客户端，不能直接使用这些 PHP 包。
- **校验**：根授权 Ed25519 签名目录、客户端清单及 SHA-256；23 个上传资产的名称、大小和摘要均已核对，Windows 下载试装通过。
