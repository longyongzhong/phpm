# PHPM 0.1.0-rc.3

Linux 默认使用 PHPM 自建签名源，首次安装无需手动注册来源或传入 `--source`。当前为待审阅草稿。

```sh
phpm php available
phpm php install 8.4
phpm init --php 8.4
phpm install
phpm ext install xlswriter
phpm ext install redis
phpm verify
```

- 自建包支持 Debian 12 x86_64 / glibc 2.36 和 Debian 13 x86_64 / glibc 2.41，系统运行库需另行准备。
- 客户端内置受控根公钥和最低目录序号；验证授权、签名、期限、系统、ABI 和包摘要后安装。失败时不切换其他来源。
- Windows 保持默认 PHP 官方 Windows 源。StaticPHP 改为显式 `--provider staticphp`；已有项目升级沿用原来的签名源或 StaticPHP 来源。
- 自定义签名源仍可通过其他名称注册和 `--source NAME` 使用；内置名 `phpm` 不接受覆盖或隐式换根。
- 本次是客户端更新，复用 rc.2 已验收的 PHP 8.4.27/8.5.12、Redis 6.3.0、xlswriter 3.0.0 和 SDK；内置默认目录固定为公开 rc.2 的签名目录。
